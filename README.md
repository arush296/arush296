## What I'm building

### 🛰️ [EuroSAT Land-Cover Classification](https://github.com/arush296/EuroSAT-Land-Cover-Classification)

An end-to-end computer-vision project comparing a custom CNN with a fully fine-tuned ResNet18 on 27,000 satellite images. It includes reproducible dataset splits, model analysis, ONNX export, a tested FastAPI backend, and a small Vercel frontend that compares both models side by side.

The final ResNet18 reached **96.93% test accuracy**, compared with **92.04%** for the custom CNN.

[Try the live demo](https://eurosat-classifier.vercel.app)

`Python` · `PyTorch` · `scikit-learn` · `ONNX Runtime` · `FastAPI` · `pytest` · `Vercel` · `Render`

### 🎓 [RMIT Job Automation](https://github.com/arush296/rmit-job-automation)

A scheduled job monitor that checks RMIT's Workday API, detects new listings with SQLite, analyses job descriptions against a private resume using Gemini, and sends formatted email alerts. It runs every two hours through GitHub Actions.

`Python` · `SQLite` · `Gemini API` · `GitHub Actions` · `SMTP`

### 🪣 [Bucket API](https://github.com/arush296/bucket-api)

A FastAPI backend for saving and organising links into searchable buckets, with asynchronous SQLAlchemy models, authentication, and structured API routes.

`Python` · `FastAPI` · `SQLAlchemy` · `SQLite` · `JWT`

### 🧪 Automated software testing

Exploring test generation and test quality using JUnit, mutation testing, code coverage, and the AsserT5 model.

`Python` · `PyTorch` · `Transformers` · `Java` · `JUnit`
